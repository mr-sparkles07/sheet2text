**sheet2text** converts spreadsheets into clean, readable plain text or Markdown.

- **Input:** CSV, XLSX, ODS
- **Output:** Plain text, Markdown
- **Usage:** Browser-based converter or standalone command-line tool
- **Privacy:** Browser conversions happen locally. No file uploads.

## Downloads

Download precompiled executables from the Releases page.

This repository contains binary releases, not source code.
